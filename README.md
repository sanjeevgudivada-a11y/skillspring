# Online Course Website

A responsive HTML and CSS college web development project.

## Files
- `index.html` — webpage structure and content
- `style.css` — colors, layout, typography and responsive design

## Run locally
Open `index.html` in a web browser.

## Deploy with GitHub Pages
1. Create a public GitHub repository.
2. Upload `index.html` and `style.css` to the repository root.
3. Open Settings → Pages.
4. Choose Deploy from a branch, select `main` and `/(root)`, then Save.
5. Open the published URL shown on the Pages screen.

## Customization
Replace the sample names, descriptions and email address with your own details before submission.
